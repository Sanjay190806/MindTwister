# JANSAHAY AI 🇮🇳
### AI-Powered Scheme Matching, Financial Planning & Channel Partner Routing
**Smart India Hackathon 2026 Prototype (Problem Statement: SIH26092 – AI Driven Scheme Matching for Marginal Entrepreneurs)**

---

## 📌 Overview
**JANSAHAY AI** is an intelligent frontend prototype designed to help marginal entrepreneurs, micro-business owners, artisans, self-employed citizens, and new founders discover suitable Government of India support schemes.

The platform analyzes an entrepreneur's profile, benchmarks eligibility against national MSME and self-employment guidelines, calculates financial repayment burdens with dynamic capital subsidies, audits document readiness, and routes the user to the nearest physical facilitation centre and designated financial channel partner.

---

## ✨ Key Features
- **5-Stage Assessment Wizard**: Structured multi-step profiling covering personal, business, financial, and document readiness parameters.
- **Explainable Rule-Based Matching Engine**: Evaluates sectors, operational stages, funding needs, and demographic categories across 8 central schemes (e.g., PMEGP, MUDRA, Stand-Up India, CGTMSE, PM Vishwakarma).
- **Interactive Financial & EMI Calculator**: Uses standard banking amortization ($EMI = \frac{P \cdot r \cdot (1+r)^n}{(1+r)^n - 1}$) to compute monthly EMI, total interest, and capital subsidy offsets.
- **Document Readiness & Missing Paperwork Support**: Audits essential compliance paperwork and provides resolution steps for pending documents (e.g., Udyam Registration).
- **Nearest Centre Locator**: Discovers nearby District Industries Centres (DICs), MSME Development Offices (MSME-DFO), and e-Seva helpdesks with demo navigation.
- **Channel Partner Routing**: Connects entrepreneurs with appropriate implementation bodies (PSU Banks, KVIC, DIC).
- **Side-by-Side Scheme Comparison**: Matrix comparing funding, mock interest rates, tenures, subsidies, and collateral terms for up to 3 schemes.
- **Citizen Dashboard**: Personalized control center with active recommendation recaps and actionable next steps.
- **SIH Test Personas**: 1-click pre-fill for test personas including **Arun Kumar (Food Processing / Chennai)**, **Pooja Sharma (Handicrafts / Jaipur)**, and **Ramesh Yadav (Agri / Varanasi)**.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Sanjay190806/MindTwister.git
cd MindTwister
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 4. Build for production
```bash
npm run build
```
